01/ Project One

Optomotor Response in 3D

Harvard · Engert Lab · Computer Vision

A 3D tracking pipeline for studying how medaka and zebrafish of different ages follow moving visual patterns in a deep arena. I stitched four cameras into one panoramic view in MATLAB, then trained SLEAP pose models and triangulated two camera views with Anipose to reconstruct each fish’s posture in 3D.

03/ Project Three

Technical Credit —
TC-ADR Manager

VS Code Extension · Software Architecture

A Visual Studio Code extension that extends Architecture Decision Records (ADRs) to capture Technical Credit information. The extension supports key Technical Credit fields including Benefit, Conditions, Signals, Confidence, Status, and Related Decisions, and offers both Basic and Professional modes along with a dashboard that aggregates Technical-Credit-annotated ADR markdown files.
