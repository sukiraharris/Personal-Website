# Sukira Harris — Personal Website

🌐 **[View the Live Website](https://sukiraharris.github.io/Personal-Website/)**

My personal portfolio — a space bringing together my work across **computer science, research, creative direction, and writing**.

Rather than treating my technical and creative work as separate, I designed this site to show how they intersect. The portfolio brings together selected software projects, research experience, creative work, and writing in one place.

---

## About

I'm **Sukira Harris**, a Computer Science student at Northeastern University concentrating in **Artificial Intelligence** with a minor in **Neuroscience**.

My interests sit at the intersection of technology, science, and creativity — from software engineering and computational neuroscience to creative direction and writing.

This website is a digital space that reflects all of those sides of my work rather than reducing them to a traditional portfolio.

## Design

I wanted the website to feel closer to an **editorial experience** than a traditional developer portfolio.

The visual direction draws from magazines, print design, and digital editorial work, using typography, imagery, layering, and interaction to create a site that feels personal while still making my work easy to explore.

The interface and visual system were designed specifically around the different kinds of work I wanted to showcase.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/sukiraharris/Personal-Website.git
```

Navigate into the project:

```bash
cd Personal-Website
```

Then open `index.html` in your browser.
